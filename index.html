Accessibility Quick Audit

Paste HTML, get WCAG findings in your browser

Paste an HTML snippet or full page source below. The tool parses it safely (never executes it) and runs a set of WCAG-aligned accessibility checks: alt text, form labels, heading structure, landmarks, link text, ARIA usage, data tables, media captions, and inline color contrast. Each finding tells you the severity, the offending element, the relevant success criterion, and a one-line fix.

Everything runs locally in your browser. The HTML you paste is never sent to any server.
